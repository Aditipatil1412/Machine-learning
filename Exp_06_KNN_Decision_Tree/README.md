# Experiment 6: K-Nearest Neighbors and Decision Tree Classification

## Aim

To implement K-Nearest Neighbors (KNN) and Decision Tree classification algorithms and compare their performance on a dataset.

## Dataset

**Breast Cancer Wisconsin Dataset**

The dataset contains features calculated from digitized images of breast mass samples. The target variable indicates whether the tumor is benign or malignant.

Dataset source: Kaggle. Add the specific dataset link you downloaded from.

## Algorithms Used

### 1. K-Nearest Neighbors (KNN)

KNN is a supervised machine learning algorithm that classifies a data point based on the majority class among its nearest neighbors. Feature scaling is applied because KNN depends on distances between data points.

### 2. Decision Tree

A Decision Tree classifies data by splitting it according to feature values. It creates a tree-like structure containing decision nodes and leaf nodes.
