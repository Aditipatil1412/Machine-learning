# Comparison of Regression Algorithms

## Aim

To implement and compare different regression algorithms for predicting continuous numerical values.

## Dataset

**California Housing Dataset**

The dataset contains information related to housing characteristics and location, which can be used to predict housing values.

Dataset source: Use the same dataset source and CSV file used in the notebook.

## Algorithms Used

### 1. Linear Regression

Linear Regression models the relationship between input features and a continuous target using a linear equation.

### 2. Polynomial Regression

Polynomial Regression adds polynomial features to model nonlinear relationships between input variables and the target.

### 3. Decision Tree Regression

Decision Tree Regression divides the data into regions using feature-based decision rules and predicts a numerical value for each region.

### 4. Random Forest Regression

Random Forest Regression combines the predictions of multiple decision trees to improve predictive performance.

### 5. Support Vector Regression (SVR)

SVR predicts continuous values by fitting a function within a specified error margin.

## Implementation

1. Import the required libraries.
2. Load and inspect the dataset.
3. Handle missing values.
4. Separate the input features and target variable.
5. Divide the dataset into training and testing sets.
6. Train the regression models.
7. Generate predictions.
8. Calculate evaluation metrics.
9. Compare the performance of the models using a graph.

## Evaluation Metrics

* Mean Absolute Error (MAE)
* Mean Squared Error (MSE)
* Root Mean Squared Error (RMSE)
* R-squared (R²) Score

Lower error values generally indicate better predictions, while a higher R² score generally indicates a better fit.
