# Machine Learning Laboratory

This repository contains the implementation of 10 laboratory experiments performed as part of the Machine Learning course in Third Year B.Tech.

The experiments cover data preprocessing, exploratory data analysis, dimensionality reduction, regression, classification, clustering, and artificial neural networks using Python and popular machine learning libraries.

## 🎯 Objectives

* Understand the fundamental concepts of Machine Learning.
* Perform data preprocessing and exploratory data analysis.
* Apply dimensionality reduction techniques to multivariate datasets.
* Implement regression and classification algorithms.
* Explore clustering techniques and artificial neural networks.
* Evaluate machine learning models using appropriate performance metrics.
* Gain practical experience with Python and machine learning libraries.

## 🛠️ Technologies and Libraries

* **Programming Language:** Python
* **Development Environment:** Jupyter Notebook / Google Colab
* **Data Processing:** Pandas, NumPy
* **Data Visualization:** Matplotlib, Seaborn
* **Machine Learning:** Scikit-learn
* **Deep Learning:** TensorFlow / Keras, where required

## 📊 Evaluation Metrics

Depending on the experiment, the following metrics and techniques are used:

* Accuracy
* Precision
* Recall
* F1-score
* Confusion Matrix
* Mean Absolute Error (MAE)
* Mean Squared Error (MSE)
* Root Mean Squared Error (RMSE)
* R² Score
* Explained Variance Ratio
* Silhouette Score

## ▶️ How to Run the Experiments

1. Clone or download this repository.
2. Open the required experiment folder.
3. Open the Jupyter Notebook (`.ipynb`) using Jupyter Notebook, JupyterLab, or Google Colab.
4. Install the required Python libraries if they are not already available.
5. Ensure the dataset path in the notebook is correct.
6. Run the notebook cells sequentially to view the outputs and results.
